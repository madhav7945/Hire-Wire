Hire-Wire Frontend

This is the React frontend for the Hire-Wire application, built for speed and real-time interaction using Vite.

Features & Tech Stack
- Framework: React 19 + Vite
- Styling: Tailwind CSS
- Real-time: Socket.io-client
- AI/ML: `face-api.js` (Face Detection) & `google-tts-api` (Text-to-Speech)

Setup Instructions

1. Install Dependencies:
   ```bash
   npm install
   ```
2. Start the Development Server:
   ```bash
   npm run dev
   ```
